\# UI Translation \& Localization Review Sheet



\## Overview

\- \*\*Languages Supported:\*\* English (`en`), Hindi (`hi`), Urdu (`ur` with RTL layout), and Dogri (`doi` in Devanagari).

\- \*\*RTL Support:\*\* Selecting Urdu flips the document direction (`html dir="rtl"`) across screens.

\- \*\*Fallback Chain:\*\* Dogri UI currently covers 243/343 strings; missing keys automatically fall back to Hindi and then English so no UI element renders blank.

\- \*\*Note:\*\* All non-English UI strings are initial drafts and require review by fluent native speakers and clinicians before production use.
